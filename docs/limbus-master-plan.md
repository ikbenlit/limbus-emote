## 2. Interactie Design (Wat we hebben gebouwd)

### Rechterhand: De "Zender" (Boodschap & Emotie)
| Gebaar | Actie / Tekst | Visueel |
|--------|---------------|---------|
| ☝️ 1 vinger | **POWER** | Rood/oranje particles, energie, pulserend |
| ✌️ 2 vingers | **FLOW** | Blauw/paars particles, vloeiend, beweging |
| 🤟 3 vingers | **CALM** | Groen/turquoise particles, zacht, rustgevend |
| ✊ Vuist | **WOEDE** | Rood agressief, vibrerende tekst |
| 🖐️ Open stil | **RUST** | Groene kalme particles, pulseert zacht |
| 👋 Open beweegt | **BLIJ** | Geel/goud, sparkles/twinkles |

### Linkerhand: De "Ontvanger" (Interactie)
| Gebaar | Actie | Effect |
|--------|-------|--------|
| ✊→🖐️ Openen | **EXPLODE** | Het actieve woord explodeert in de lucht |
| 🖐️→✊ Sluiten | **CATCH/IMPLODE** | Particles worden naar de vuist gezogen |

## 3. De 60s Demo Flow (Het Script)

| Tijd | Fase | Actie |
|------|------|-------|
| 0:00 | **Intro** | Hand komt in beeld, neutraal. |
| 0:05 | **Cijfers** | ☝️ 1 → **POWER**, ✌️ 2 → **FLOW**, 🤟 3 → **CALM**. |
| 0:24 | **Emotie** | ✊ Vuist → **WOEDE**. |
| 0:32 | **Interact** | Linkerhand opent → **EXPLOSIE** van de "WOEDE" tekst. |
| 0:38 | **Rust** | 🖐️ Open stil → **RUST**. |
| 0:44 | **Blij** | 👋 Zwaaien → **BLIJ** (sparkles). |
| 0:50 | **Catch** | Linkerhand sluit → **CATCH** (particles trekken naar hand). |
| 0:56 | **Outro** | Tekst: "MediaPipe + Three.js + één avond". |
